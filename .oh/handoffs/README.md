# handoffs

Session handoff notes — what shipped, what's pending, and what the next
session needs to know. One file per handoff, named
`<YYYY-MM-DD>-<project>-<slug>.md`.

Distinct from `.oh/context/IDENTITY.md` (append-only principles) and `.oh/plans/`
(pre-execution plans): a handoff is the post-session state of a work stream.
