# progress — apache-relicense

## Codebase Patterns

- `origin` (`ryaneggz/openharness`) is the operator's fork; `upstream` (`mifunedev/openharness`) is
  the canonical public repo. A license assertion is only legally meaningful upstream, so this branch
  is cut from `upstream/development` and the PR targets `upstream:development`. Upstream merges do
  NOT auto-close issues — close #666 manually.
- `CLAUDE.md` is a symlink to `AGENTS.md`; edit `AGENTS.md` only.
- `.oh/evals/probes/skills-dir-clean.sh` walks `find "$SKILLS" -maxdepth 1 -mindepth 1 -type f`, so
  per-skill `LICENSE` files at depth 2 are invisible to it. Deleting them cannot break that probe.
- npm force-includes `README` and `LICENSE` in a published tarball but NOT `NOTICE`. Any package
  using an explicit `files` array must list `NOTICE` or it silently ships without one.
- `.devcontainer/Dockerfile` is a protected path (`.claude/protected-paths.txt`). This task declares
  an additive-only override: one new LABEL line, zero deletions.
- Eight files mention MIT in reference to OTHER projects and must stay byte-identical. The list is
  prd.md section 9. Never run a blind repo-wide MIT→Apache replacement.
