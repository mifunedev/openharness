## Codebase Patterns

- Root `docs/` is project-owned Markdown and category metadata. The `.oh/` payload remains scoped to `.oh/` and must not copy or overwrite root documentation.
- When moving a documentation root, adjust relative links by one traversal level: root docs use `../.oh/...` for control-plane files and `../...` for repository-root files. Keep rendered-site `/docs/...` URLs unchanged.
